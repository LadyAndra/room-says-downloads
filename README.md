# Room Says

Downloads for **Room Says**, the live survey game show for parties, events and work retreats.

## Get the newest version

- **Mac** (Apple chip and Intel): [Room-Says-Mac.dmg](https://github.com/LadyAndra/room-says-downloads/releases/latest/download/Room-Says-Mac.dmg)
- **Windows**: [Room-Says-Windows-Installer.exe](https://github.com/LadyAndra/room-says-downloads/releases/latest/download/Room-Says-Windows-Installer.exe)
- **Windows, no install needed**: [Room-Says-Windows-Portable.exe](https://github.com/LadyAndra/room-says-downloads/releases/latest/download/Room-Says-Windows-Portable.exe)

You will need the license key from your order the first time you open Room Says.

## Opening it the first time

**Mac:** open the downloaded file and drag Room Says into your Applications folder, then open it from there.

**Windows:** if a blue box says "Windows protected your PC", click **More info**, then **Run anyway**. This only happens once.

Questions? Message the shop where you bought Room Says, with your order number.
